# 05 — Project management home screen

**What to build:** The Launcher opens to a home screen listing the user's Projects. They can create a new Project or resume an existing one; entering a Project opens a Claude Code chat scoped to that Project. Each Project is its own folder in the Workspace and persists.

**Blocked by:** 04 — Launcher skeleton.

**Status:** done

- [ ] The Launcher opens to a home screen listing existing Projects (rather than straight into a chat).
- [ ] The user can create a new Project, which appears as its own folder in the Workspace.
- [ ] Entering a Project opens a chat whose working directory is that Project.
- [ ] Creating two Projects and switching between them keeps each Project's files separate and persistent across restarts.
