# The graph

Open this folder as an Obsidian vault (Open folder as vault), then start at [[Architecture MOC]] and press the graph icon.

It is generated — edit `CONTEXT.md`, the ADRs or the code, then re-run `python3 scripts/obsidian-graph.py`.

`How it works.canvas` is hand-drawn and NOT generated — open it to walk someone through the system in one screen.
