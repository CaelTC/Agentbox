# Threat Model

The harms [[Agentbox]] exists to prevent — (A) damage to the [[Sandbox User]]'s own computer, and (B) any path from the sandbox to company systems, credentials, or private repos. [[Export]] adds (C): content produced inside the Box being executed on the host after the [[Sandbox User]] carries it across. [[The Box]]'s walls cannot defend C, because C happens outside them.
